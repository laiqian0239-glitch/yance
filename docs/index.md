# Yance

Yance is a desktop relationship and messaging workspace that connects authorized communication accounts through mature platform integrations.

For Facebook Page / Messenger, Yance uses Meta's official platform authorization and Chatwoot's Facebook Page integration, with Matrix/Element for the conversation experience.
