## 已完成

### 1. OpenRouter 能力分类器升级

模型目录同步后先识别真实输入/输出能力，再决定可参与的任务：

- 文本输入 / 文本输出
- 图片、音频、视频输入
- 图片、音频、视频输出
- 仅生成模型
- 结构化回复适配
- 翻译、快速回复、导演、深度回复、媒体分析、记忆提取任务资格

Lyria、图片生成、音频生成、视频生成、嵌入、重排、内容安全、代码专用和转写专用模型不会再进入聊天回复商业评估。

### 2. 目录同步与商业评估状态分离

系统现在分别记录：

- 远程目录数量
- 已注册数量
- 任务适配数量
- 商业评估短名单
- 已实际测试数量
- 尚未评估数量
- 各任务主备覆盖情况

同步数百个模型不再被表述为数百个模型都已完成评估。

### 3. 模型资格分层

模型状态明确拆分为：

1. 目录可见
2. 连接可用
3. 真实调用成功
4. 当前任务能力匹配
5. 商业质量评估通过
6. 正式自动路由资格

条件试运行或待评估模型只能由用户人工指定试用，不再进入自动推荐主路由。

### 4. 翻译任务正式分流

- 实时接收翻译：通过中德商业评估的云端主模型与备用模型
- 中文输入外发：通过中德商业评估的云端主模型与备用模型
- 历史消息：本地模型低优先级批量处理
- 断网：本地临时译文，不直接获得正式自动外发资格

`translategemma:4b` 不再仅因调用成功而被认定为正式实时翻译质量通过。

### 5. 回复与导演路由门禁

正式回复大脑必须同时具备：

- 快速回复合格主模型与备用模型
- 深度回复合格主模型与备用模型
- 导演合格主模型与备用模型
- 商业翻译合格主模型与备用模型

空导演路由、仅条件可用模型或仅有一次成功调用的模型不能使 AI 大脑显示正式就绪。

### 6. AI 工作台状态真实性

工作台现在区分：

- 已启用任务
- 已配置任务
- 实际可运行任务
- 被阻断任务

不再以“11 个开关已启用”冒充“11/11 正式配置完成”。

### 7. 联系人菜单清理的代码债务同步删除

已删除右键菜单去重后遗留但不再使用的静音、重点联系人和复制身份辅助函数，防止隐藏重复入口继续存在。

### 8. 本地语音安装链真实修复

审查发现语音安装服务仍指向已从干净源码中删除的根目录脚本，实际点击安装会失败。现已：

- 新增 `tools/runtime-delivery/install-local-whisper.ps1`
- 由服务端调用当前权威脚本
- 动态获取 whisper.cpp Windows x64 制品
- 安装 `ggml-base.bin`
- 尝试安装并定位 FFmpeg
- 写入真实安装状态文件
- 脚本使用 ASCII + CRLF，兼容 Windows PowerShell 5.1

### 9. 历史 Fix 根目录执行入口治理

旧 Fix9–Fix17、旧 Worker 部署、旧头像安装、旧源码启动器等根目录可执行脚本不再被当前商业产品回归要求恢复。相关回归已改为验证：

- 历史执行入口不在产品源码根目录
- 当前权威 JS 服务与运行入口仍保留必要能力
- 发布、部署和真实 UAT 由后续单一材料包入口提供

这避免为了让旧测试通过而重新把过时脚本塞回商业产品。
