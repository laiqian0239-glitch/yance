# 言策 Windows 源码 UAT 逐页检查表

## 执行原则

- 使用 `START_YANCE_SOURCE_UAT.cmd` 先做隔离数据视觉与基础功能检查。
- 需要验证现有账号、历史消息和真实平台时，完全退出已安装版本后使用 `START_YANCE_SOURCE_UAT_EXISTING_DATA.cmd`。
- 每发现一个明显问题立即记录并修复，不先运行完整 Pipeline、WP7、STRICT 或 Builder。
- 每次修复后只回归相关页面和相邻平台，避免修好一个平台却破坏另一个平台。
- 源码 UAT 通过不等于正式发布通过。

## 0. 启动闭环

- [ ] 双击启动入口后 Electron 窗口真实出现，不停留在空白页或命令窗口。
- [ ] backend 在 60 秒内进入 ready；失败时界面和日志给出可读原因。
- [ ] 已安装版本占用端口时，源码 UAT 明确拒绝启动，不杀死已有进程。
- [ ] 隔离数据模式使用 `%LOCALAPPDATA%\Yance-Source-UAT`。
- [ ] 现有数据模式只在用户显式选择时使用 `%APPDATA%\Yance`。
- [ ] 退出窗口后 backend、Electron 和端口均释放。

## 1. 聊天工作区

- [ ] WhatsApp、Telegram、Facebook 切换后标题、头像、消息和账号路由不串号。
- [ ] 消息列表、输入框、引用、右键菜单、翻译和 AI 候选均可操作。
- [ ] 新消息、未读数、发送中、成功、失败和重试状态一致。
- [ ] 输入框文字不会因贴纸、GIF 或失败发送而静默丢失。
- [ ] 中文理解和外语原文同时可见，缺少译文时显示“待生成”。

## 2. 联系人与头像

- [ ] 三个平台联系人列表均检查，不以单个平台结果代替其他平台。
- [ ] 头像加载、占位头像、刷新和缓存失败降级一致。
- [ ] 联系人右键菜单项目真实可执行，平台不支持项不伪装可用。
- [ ] 多账号筛选、搜索、置顶、归档和未读数不串号。

## 3. 客户档案

- [ ] 已确认事实与 AI 推断明确分区。
- [ ] 承诺、边界、里程碑、风险和下一步为中文优先可读卡片。
- [ ] 外语原文保留，中文展示不覆盖权威原始数据。
- [ ] 没有中文翻译时显示待生成，不把字段名或外语误当中文。
- [ ] 编辑和确认后刷新页面，数据仍保持一致。

## 4. 关系轨迹

- [ ] 关系摘要、阶段、机会、风险、证据、事件和话题均可阅读。
- [ ] 每条证据可追溯到真实消息或明确来源。
- [ ] 推断不冒充事实，建议保留用户最终决定权。
- [ ] 时间顺序、联系人隔离和平台来源正确。

## 5. Persona 与学习

- [ ] Persona 显示为中文结构化卡片，而不是裸 JSON。
- [ ] 高级 JSON 审计入口仍可用，但不作为默认阅读界面。
- [ ] 联系人、平台和全局学习范围隔离。
- [ ] 接受、编辑、拒绝后的学习质量指标真实更新。
- [ ] 下一次候选回复可以参考学习结果，但不复制其他联系人的私人事实。

## 6. 29 套主题

- [ ] 逐套切换并检查侧栏、顶部栏、卡片、弹窗、输入框、菜单和 Toast。
- [ ] 文本对比度、边框、悬停、选中和禁用状态可辨认。
- [ ] 不出现透明结构面、固定旧颜色或主题切换残影。
- [ ] 三个平台页面和设置页使用同一语义颜色权威。

## 7. 诊断与持续提示

- [ ] 导出成功后只显示成功提示，文件真实存在。
- [ ] 导出失败时显示准确原因，不出现“已导出但提示失败”。
- [ ] Toast 到期后自动消失；切换页面后不持续覆盖其他界面。
- [ ] 同一错误不无限重复；关闭或处理后状态清除。
- [ ] 诊断包不包含账号 Secret、私钥或完整聊天数据库。

## 8. 设置、模型与 AI

- [ ] 设置保存后立即生效，重启后仍保留。
- [ ] Ollama 模型扫描、选择、超时和失败降级状态准确。
- [ ] 11项权威AI任务分别显示真实路由状态：翻译、事实提取、记忆提取、会话理解、关系分析、快捷回复、导演、深度回复、媒体分析、人格改写和语音转写。
- [ ] 记忆提取、媒体分析和人格改写不再借用其他任务名称或路由。
- [ ] AI 候选速度可接受，不因不必要的串行检查明显阻塞聊天。
- [ ] 翻译、Persona、学习和模型上下文均按账号与联系人隔离。
- [ ] 离线、断网和重连时设置及发送队列不损坏。

## 9. Telegram 原生素材

- [ ] 当前登录账号能读取最近贴纸和已保存 GIF。
- [ ] WebP、TGS、WebM 和已保存 GIF 分别真实发送。
- [ ] opaque 引用过期后给出刷新提示。
- [ ] 账号 A 的引用不能在账号 B 使用。
- [ ] TGS 当前仅显示格式图标，不冒充 Lottie 已播放。
- [ ] 原生贴纸发送后输入框文字保留。

## 10. Facebook 生产前置

- [ ] 公开预检读取真实 Worker、Callback、Webhook、Graph Version、Business Login ID、D1 和 R2。
- [ ] Wrangler 已登录环境可解析现有真实 D1 ID。
- [ ] 工具不读取、写入或打印任何 Secret。
- [ ] 没有 `pages_read_engagement` 时明确显示仅支持新消息收发。
- [ ] 未部署 Worker、未完成真实 OAuth 前不得显示“生产已就绪”。

## 11. WhatsApp 能力边界

- [ ] 只显示真实聊天历史素材和有效本地导入。
- [ ] 未接入原生收藏/最近贴纸目录时明确说明。
- [ ] 不出现伪 GIF、装饰性动态贴纸或不可发送的假入口。
- [ ] 发送节奏、引用、撤回和媒体状态符合真实能力。

## 12. 音效与通知

- [ ] 136套内置音效可搜索、试听并正确保存。
- [ ] 用户上传音效、自定义事件映射和重启恢复正常。
- [ ] Facebook不显示平台不支持的联系人上下线音效。
- [ ] 音频对象释放，连续试听不会持续增加内存。

## 13. 本轮结束条件

只有以下条件满足后，才进入一次正式完整验收：

- [ ] 所有页面的明显视觉和交互问题已修复。
- [ ] 三个平台相邻功能回归没有新增串号或能力倒退。
- [ ] 29 套主题完成真实 Electron 检查。
- [ ] 真实 Telegram 素材发送完成。
- [ ] Facebook 生产联调边界已明确并有真实结果。
- [ ] 源码工作树干净，形成新的 Commit、Tree、Tag 和恢复包。
