# Batch40 Windows 一键验收包设计

## 目标

用户只需下载一个 ZIP、解压并双击入口。脚本自动校验源码载荷、准备隔离的 Node.js 22.16.0/npm 10.9.2、安装依赖、运行 Batch40 聚焦测试与完整 backend runner、验证严格终态并生成证据 ZIP。

## 设计

- 交付包内嵌已修复完整源码 ZIP，避免用户手工配对文件。
- `RUN_ACCEPTANCE.cmd` 只负责启动同目录 PowerShell；核心流程在 `RUN_ACCEPTANCE.ps1`。
- Node 使用官方 Windows x64 ZIP，固定 URL 与 SHA-256，下载后先校验再解压，不修改系统 PATH、不要求管理员权限。
- 源码载荷使用固定 SHA-256；每次运行解压到独立时间戳目录。
- `npm ci`、聚焦测试、完整 runner 和证据校验逐项执行，任一步失败即返回非零状态，同时保留日志。
- 最终输出目录包含环境清单、所有命令日志、严格自动化收据、文件哈希清单、运行摘要和证据 ZIP。外部平台证据仍明确标记为待采集，不提升发布状态。

## 安全与失败策略

- 仅允许 Windows x64/AMD64。
- TLS 1.2 下载 Node 官方归档，固定哈希不匹配立即停止。
- 不执行源码 ZIP 外的动态脚本；依赖安装使用锁文件和 `npm ci`。
- 证据摘要始终记录失败步骤和退出码；成功只表示本机自动化源码门禁通过。

## 验证

- Node 单元测试检查生成脚本的固定版本、URL、哈希、载荷绑定、fail-closed 控制流及证据归档。
- 在当前非 Windows 环境执行生成器测试和现有 Batch40 聚焦测试。
- 对最终 ZIP 执行完整性检查并生成 SHA-256。
