# 言策网页伴侣 · Facebook

## 能力

- 批量补全 Business Suite 当前已加载联系人的头像。
- 增量识别新增头像、头像变化与无需更新的联系人。
- 预览网页可见会话与言策数据库之间的潜在新会话和最近消息摘要差异。
- 正式消息仍由 Meta API / Cloudflare Worker 拉取确认，网页内容不会直接写入消息库。
- 不读取 Cookie、Token、密码或 Facebook 登录凭据。

## 首次安装

1. 运行源码根目录的 `INSTALL_FACEBOOK_AVATAR_IMPORTER.cmd`。
2. Chrome 打开扩展程序页面后，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择脚本打开的扩展目录。
4. 扩展固定 ID：`jpdfcngpmkhejmehmphmfkbhkinccdoe`。

## 每次使用

1. 启动言策，进入“统一账号中心 → Facebook → 诊断”。
2. 点击“开启网页伴侣”，生成 10 分钟本机会话。
3. 打开 Meta Business Suite 收件箱。
4. 点击右下角“言策网页伴侣”中的“自动滚动扫描与对账”。
5. 查看新增头像、头像变化、潜在新会话及消息摘要差异。
6. 仅对新增或变化头像执行一次确认导入。

扩展只在用户主动操作时读取 Business Suite 页面已经显示的联系人名称、头像和最近消息摘要。头像直接写入本机言策缓存和 SQLite，并记录来源、导入时间、匹配依据及人工确认状态。
